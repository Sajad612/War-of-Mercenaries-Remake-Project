# Game Research & Asset Analysis Project

مشروع بحثي لدراسة وتحليل لعبة قديمة بهدف التعلم وفهم بنية الألعاب القديمة وتقنيات تطويرها.

## About

يحتوي هذا المستودع على:
- الأصول التي تم تحليلها واستخراجها لأغراض البحث.
- الأدوات المستخدمة في فحص وتحليل الملفات.
- ملاحظات حول طريقة استخراج وفهم بنية ملفات اللعبة.

## Technologies Analyzed

- Adobe AIR
- Starling Framework
- ATF Texture Format
- Flash / ActionScript
- Stage3D Rendering

## Tools Used

- ATF Extractor
- Asset Analyzer
- Adobe AIR SDK Tools
- أدوات تحليل الملفات الثنائية

## Extraction Process

تم تحليل ملفات اللعبة عبر الخطوات التالية:

1. فحص ملفات التطبيق الأصلية وتحديد نوع الملفات المستخدمة.
2. استخراج ملفات الموارد المضمنة داخل الحزمة.
3. تحليل ملفات Texture بصيغة ATF ومعرفة:
   - الأبعاد
   - صيغة الضغط
   - دعم Alpha
   - استخدام MipMaps
4. اختبار تحميل الأصول باستخدام Starling Framework.
5. إنشاء أدوات صغيرة لعرض وفحص الموارد المستخرجة.
